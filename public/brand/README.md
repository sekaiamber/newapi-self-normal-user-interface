# SwarmRouter 品牌资源

- 来源：owner 于 2026-10-05 提供的 logo 组（原文件未修改）：`swarmrouter-logo.svg`（图标 + 文字）、`swarmrouter-wordmark.svg`（文字）、`swarmrouter-icon.svg`（蜂巢图标）。
- `*-dark.svg`：暗色背景用的派生版本，只把近黑色 `#202226` 替换为 `#f2efe8`，金色不变。
- 品牌色：主题金 `#d6a51d`，近黑 `#202226`。
- 对比度（WCAG）：金底白字约 2.3:1、白底金字约 2.3:1，均不达标；金底近黑字、近黑底金字约 7.0:1。
  因此：金色按钮/徽章上的文字用近黑色；浅色背景上的金色文字（链接、强调字）需改用更深的金色；暗色背景上可直接用主题金。
